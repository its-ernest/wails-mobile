# wails-mobile/wails/permission

This is an officially maintained `Permission` package for Android and iOS which comes pre-installed in the wails-mobile project.

More information into the architecture is found in `DOCS.md` generated by `gomarkdoc`

---

## Setting up permission plugin for your app

From your engine.go, initialize and bind the plugin in the `StartApplication` function, as shown below:

```go
// permPlugin is a global instance of the permission plugin to be initialized on app start
var permPlugin = permission.NewPlugin()

// StartApplication initializes the mobile backend runtime from Android.
func StartApplication() string {
	helloService := NewAppService()

	app := wails.NewApplication(wails.Options{
		Name:   "HelloWorld",
		Assets: assets,
		Bind: []interface{}{
			helloService,
			permPlugin, // add it to Bind
		},
		OnStart: func(app *wails.Application) error {
			// Initialize the permission plugin with the application context
			if err := permPlugin.Init(app); err != nil {
				return err
			}

			return nil
		},
	})

	if err := app.Run(); err != nil {
		return fmt.Sprintf(`{"error":"%s"}`, err.Error())
	}

	return `{"status":"started"}`
}

```

## Requesting a Permission

From your frontend, presumably `app.js`

```js
// Button to trigger permission request
document.getElementById('request-perm').addEventListener('click', async () => {
	try {
		await Wails.CallGo('PermissionPlugin.Request', "android.permission.CAMERA");
		updateOutput("Requested camera... check the system dialog.");
	} catch (err) {
		updateOutput(`Error: ${err.message}`);
	}
});
```

## Checking if permission is granted

From the javascript:

```js
document.getElementById('check-perm').addEventListener('click', async () => {
    try {
        // Use the CallNative helper which handles stringify and response parsing
        const result = await CallNative('permissions:check', { permission: "android.permission.CAMERA" });
        //asknowledge
        updateOutput(`Camera Status: ${result.status}`);
    } catch (err) {
        updateOutput(`Error: ${err.message}`);
    }
});
```
